# 3  使用镜像 hou6807628/webdav
```
docker run --restart always --name webdav -d \
  -e USERNAME=你的用户名 -e PASSWORD=你的密码 \
  -v /srv/你的共享文件夹绝对路径:/webdav \
  -p 8080:80 hou6807628/webdav
```
